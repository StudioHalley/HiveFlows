# Skill : Exemple

Un skill de démonstration pour tester le système de skills HiveFlows.

## Capacités

- Générer un message de bienvenue personnalisé
- Afficher les informations système de base

## Scripts disponibles

- `scripts/hello.py` — Affiche un message de bienvenue personnalisé. Accepte un argument `name` (optionnel).
- `scripts/sysinfo.sh` — Affiche les informations système (OS, hostname, date, uptime).

## Utilisation

Pour exécuter un script de ce skill, utilise `run_script` avec le contenu du fichier ou invoque-le directement.
